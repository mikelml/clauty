# skills/ de la semilla

Vacía a propósito (T2.3.08).

La semilla no trae skills: un Clauty en blanco no sabe hacer nada que tú no hayas aprobado. Las skills base (presentarse, proponer-aprobar-aplicar, recordar, "si estás leyendo esto"…) llegan con el instalador de [`openclaw/`](../../openclaw/README.md) y con la edición (T4.7), cada una fijada por hash.

Agregar una skill aquí es un evento de crianza: entra en `estado: propuesta` y no se usa hasta que el dueño la aprueba. El formato de una skill está en [`alma/README.md`](../../alma/README.md#6-skills).
